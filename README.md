# taskmaster-backend
Spring Boot REST API for collaborative task tracking and project organization.   This backend allows users to register, log in securely, create teams, manage tasks, assign work, add comments, upload attachments, and collaborate efficiently.

## Features

- User registration and login
- JWT-based authentication and authorization
- Profile management
- Team and project creation
- Team member invitation and task assignment
- Task CRUD operations
- Task filtering, sorting, and search
- Comments on tasks
- Attachments for tasks
- Validation and centralized error handling
- RESTful API design
- Optional real-time notifications
- Optional AI-generated task descriptions

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Maven
- Flyway
- JWT
- OpenAPI / Swagger
